# Navigation vs. edit mode

| Mode | Keys |
| --- | --- |
| Edit (cell editor focused) | `Escape` → navigation · `Shift+Enter` run & advance · `Ctrl+Enter` run & stay · `Alt+Enter` run & insert below |
| Navigation (cell list focused) | `Enter` edit · `j` / `k` next / previous · `a` / `b` insert Python cell above / below · `m` / `y` to Markdown / Python · `d d` delete |
| Anywhere in the notebook | `Alt+J` / `Alt+K` select next / previous cell |

The status bar shows `QMD: NAV` or `QMD: EDIT`. Single-letter keys only fire when no text input has focus.
